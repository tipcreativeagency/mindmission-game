# Project instructions

This folder packages the MINDMISSION Pygame game for browser testing and static hosting.

- Keep the original game source in the parent workspace unchanged.
- `main.py` is the browser-ready copy used by Pygbag.
- Root-level runtime files are required by `index.html`; do not rename them without updating the loader.
- Do not include unrelated attachment scripts or credentials.
- The `.apk` file is a Pygbag browser bundle artifact, not an Android install package.
